# Изменения 1.0.0

- Вместо неполного прототипа подключены все разделы CLI и мастера.
- Добавлены точные снимки, восстановление SQLite и файлов, независимый постоянный systemd-откат и защита от поздней записи процесса применения.
- Реализованы загрузка конкретных официальных релизов, проверка архивов, 3x-ui API с CSRF/2FA, Reality и каскад с проверкой настоящим Xray.
- Добавлены профили IP/DNS для сетевых менеджеров, сертификаты ACME, UFW/SSH/Fail2ban и возобновляемая быстрая настройка.
- Добавлены атомарное локальное обновление, сборка дистрибутива, unit/API/Xray-тесты и Linux/systemd CI.
